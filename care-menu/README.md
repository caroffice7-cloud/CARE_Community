# 보성 통합돌봄 메뉴판 웹사이트

보성군 기본소득 지역화폐(월 20만원)로 결제하는 거동불편 어르신 방문·배달형 통합돌봄
서비스 메뉴판을, **고객이 직접 보고 골라 신청할 수 있는 웹사이트**로 만든 것입니다.

운영: 농업회사법인 히스메이커스(주) · 자연사랑 생활장터 · BMC 마을방송국

---

## 1. 무엇이 되나요

| 화면 | 파일 | 하는 일 |
|---|---|---|
| 메뉴판 + 신청 | `index.html` | 7개 분류 39개 서비스를 보고 담기 → 월 20만원 예산 실시간 계산 → 신청서 작성·제출 |
| 운영자 접수함 | `admin.html` | 들어온 신청 확인, 어르신께 바로 전화, 엑셀(CSV) 내려받기 |
| 접수 서버(선택) | `apps-script/Code.gs` | 신청서를 구글 스프레드시트에 자동으로 쌓고 담당자에게 메일 알림 |

메뉴판 화면의 기능

- **담기 / 수량 조절** — 1회성 서비스는 횟수를, 월정액은 한 번만 담습니다.
- **장보기 배달처럼 금액이 달라지는 항목**은 월 예상 금액을 직접 적습니다.
- **예산 막대** — 분류별로 색이 나뉘어 어디에 얼마를 쓰는지 한눈에 보이고,
  20만원을 넘으면 초과 금액을 붉게 알립니다.
- **AI 데이터 참여 포인트** — 방언 녹음·구술 기록에 참여하면 적립 포인트만큼
  사용 가능 금액이 늘어납니다 (1P = 1원).
- **추천 패키지 4종**을 한 번에 담고 필요한 대로 고칠 수 있습니다.
- **큰 글씨 모드**, 어두운 화면 자동 대응, 휴대폰 화면 대응, 인쇄·PDF 저장.
- 담은 구성과 쓰다 만 신청서는 브라우저에 저장되어, 창을 닫았다 열어도 남아 있습니다.

## 2. 신청은 어떻게 접수되나요

접수 서버 연결 여부에 따라 두 가지로 동작합니다.

**(가) 접수 서버를 연결하지 않은 상태 (기본값)**
신청서를 제출하면 접수번호가 발급되고, 신청서 전문이 화면에 만들어집니다.
고객은 **[문자로 보내기] · [전화 걸기] · [신청서 복사] · [인쇄]** 중 하나로 접수를 마칩니다.
작성 내용은 그 기기에 저장되어 `admin.html`에서 볼 수 있습니다.
→ 별도 서버 없이 바로 쓸 수 있어 시범사업 초기에 적합합니다.

**(나) 구글 스프레드시트 접수 서버를 연결한 상태**
제출과 동시에 구글 시트에 한 줄씩 쌓이고, 담당자 메일로 알림이 갑니다.
고객 화면에는 "접수되었습니다"가 뜹니다.

연결 방법은 `apps-script/Code.gs` 파일 맨 위 주석에 순서대로 적어 두었습니다.
배포하고 받은 웹 앱 주소를 `assets/config.js`의 `endpoint`에 넣으면 끝입니다.

## 3. 고쳐 쓰는 법

- **연락처·전화번호·한도 금액** → `assets/config.js` (개발 지식 없이 고쳐도 되는 파일)
- **서비스 항목·가격·설명·추천 패키지** → `assets/data.js`
- **색·글꼴·여백** → `assets/styles.css` (모든 색은 파일 맨 위 토큰에서 한 번에 바뀝니다)
- **화면 동작** → `assets/app.js`

가격을 고칠 때는 `data.js`의 `price` 숫자만 바꾸면 메뉴판·패키지 합계·예산 막대가
모두 따라서 바뀝니다.

## 4. 올리는 법

빌드 과정이 없는 순수 HTML/CSS/JS입니다. 파일을 그대로 올리면 됩니다.

- **GitHub Pages** — 저장소 Settings → Pages → 브랜치 지정 후
  `https://<사용자>.github.io/<저장소>/care-menu/` 로 열립니다.
- **바로 보기** — `index.html`을 더블클릭해도 동작합니다(접수 서버 연결 시에는 웹 주소 필요).

## 5. 시범 운영 전 확인할 것

1. 지역화폐 가맹점 업종 코드 확인 — 돌봄 용역·소매업 중 결제 가능 업종 구분
2. 서비스별 제공 주체 확정 — 자사 직접수행 / 마을 주민 위탁 / 기존 재가센터 연계
3. 배상책임보험 가입 및 종사자 안전교육 이수
4. 시범 대상 10~20가구 선정 후 3개월 실증 → 단가 재조정
5. AI 데이터 참여 동의서 별도 서식 마련 (개인정보 비식별·활용 범위 명시)

신청서에는 어르신 성함·연락처·주소·건강 특이사항이 담깁니다.
접수 시트와 운영자 화면은 담당자만 볼 수 있게 공유 범위를 제한하세요.
