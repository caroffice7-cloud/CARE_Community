# 서버에 올리기 전에, 내 PC에서 먼저 보기

배포하기 전에 대표님 컴퓨터에서 먼저 돌려 보고 검토하실 수 있습니다.
**인터넷에 공개되지 않고 대표님 PC 안에서만 열립니다.**

---

## 먼저 알아 두실 것 — HTML 파일만으로는 안 됩니다

이 프로그램은 단순한 웹페이지가 아니라 **서버가 함께 돌아가는 프로그램**입니다.

```
화면(HTML)  ──"메뉴 목록 주세요"──▶  서버  ──▶  데이터베이스
                                  (계산·저장)
```

잔액 계산, 월 한도 차단, 정산, 회원 관리가 전부 서버 쪽에 있습니다.
그래서 `index.html` 파일을 더블클릭해서 열면 **틀만 보이고 내용은 비어 있습니다.**

대신 아래 방법으로 **서버까지 대표님 PC에서 함께 돌리면** 실제와 똑같이 보실 수 있습니다.

---

## 1단계 — Node.js 설치 (한 번만)

1. https://nodejs.org 접속
2. 왼쪽의 **LTS** 버튼 클릭해서 내려받기
3. 내려받은 파일 실행 → 계속 "다음"만 누르면 설치 완료

> 이미 설치되어 있다면 건너뛰세요. 확인하려면 명령 프롬프트에서 `node -v` 를 입력했을 때
> `v22.` 이상이 나오면 됩니다.

---

## 2단계 — 코드 내려받기

### 가장 쉬운 방법 (ZIP 파일)

1. 아래 주소를 브라우저에 붙여넣습니다.
   ```
   https://github.com/caroffice7-cloud/CARE_Community/archive/refs/heads/claude/local-currency-market-system-g6jdss.zip
   ```
2. 내려받은 ZIP 파일을 **압축 해제**합니다. (예: 바탕화면에 풀기)
3. 풀린 폴더 안에 `server.js`, `시작하기-윈도우.bat` 같은 파일이 보이면 됩니다.

### 익숙하시다면 (Git)

```bash
git clone -b claude/local-currency-market-system-g6jdss https://github.com/caroffice7-cloud/CARE_Community.git
```

---

## 3단계 — 실행

폴더 안의 파일을 **더블클릭**하면 됩니다.

| 운영체제 | 실행할 파일 |
| --- | --- |
| 윈도우 | `시작하기-윈도우.bat` |
| 맥 | `시작하기-맥용.command` |

검은 창이 뜨고, 3초 뒤 브라우저가 자동으로 열립니다.

> **맥에서 "확인되지 않은 개발자" 경고가 뜨면** — 파일을 마우스 오른쪽 클릭 →
> "열기" → 다시 "열기"를 누르면 실행됩니다.

### 열리는 화면

| 화면 | 주소 | 로그인 |
| --- | --- | --- |
| 고객 화면 (어르신·보호자) | http://localhost:3000/ | 로그인 없음 |
| 운영자 화면 | http://localhost:3000/admin | 아이디 `admin` / 비밀번호 `boseong2026` |

**끄실 때는 검은 창을 닫으면 됩니다.**

## 검토하실 때 눌러 보시면 좋은 것

### 고객 화면
- [ ] 글씨 크기와 버튼 크기가 어르신이 쓰시기에 적당한가
- [ ] "추천 패키지 → 이 패키지 담기" 를 눌러 장바구니가 제대로 담기는가
- [ ] 위쪽 초록색 잔액 바가 담을 때마다 줄어드는가
- [ ] 20만원을 넘겨 담으면 빨간 경고가 뜨는가
- [ ] "생활장터 장보기" 탭에서 카카오톡 문장을 붙여넣어 보기
      (예: `백미 10kg 1포, 계란 2판, 두부 3모 주세요`)
- [ ] 서비스 희망일 입력란이 돌봄 항목을 담았을 때만 나타나는가
- [ ] 휴대폰으로도 열어 보기 → 같은 와이파이라면 PC의 IP 주소로 접속 가능
      (명령 프롬프트에 `ipconfig` 입력 → IPv4 주소 확인 → 휴대폰에서 `http://그주소:3000`)

### 운영자 화면
- [ ] 접수 현황에 방금 넣은 신청이 보이는가
- [ ] 방문 일정 화면에 날짜별로 정리되어 보이는가
- [ ] 상태를 "취소"로 바꾸면 24시간 전/당일 자동 판정이 뜨는가
- [ ] 회원 관리에서 월 한도를 바꾸면 잔액이 바로 반영되는가
- [ ] 운영자 계정에서 담당자 계정을 하나 만들어 보고, 그 계정으로 로그인했을 때
      설정·단가 메뉴가 숨겨지는가
- [ ] 정산 화면에서 CSV 내보내기를 눌러 엑셀로 열리는가

## 자주 겪는 문제

| 증상 | 해결 |
| --- | --- |
| 검은 창이 바로 닫힘 | Node.js가 설치되지 않았습니다. 1단계를 다시 하세요. |
| "포트가 이미 사용 중" | 다른 프로그램이 3000번을 쓰고 있습니다. 창을 닫고 잠시 뒤 다시 실행하세요. |
| 브라우저에 아무것도 안 뜸 | 검은 창이 켜져 있는지 확인하세요. 꺼져 있으면 서버도 꺼진 것입니다. |
| 화면은 뜨는데 내용이 빔 | `index.html` 을 직접 연 경우입니다. 반드시 `시작하기` 파일로 실행하세요. |
| 처음부터 다시 보고 싶음 | `data` 폴더의 `care.db` 파일을 지우고 다시 실행하면 초기 상태가 됩니다. |

---

## 검토가 끝나면

내 PC에서 만든 데이터(`data/care.db`)는 **서버로 옮기지 않습니다.** 검토용이므로
실제 운영은 서버에서 깨끗한 상태로 새로 시작합니다.

서버 배포는 [DEPLOY.md](DEPLOY.md) 를 보시거나, 서버가 준비되면 함께 진행하겠습니다.
